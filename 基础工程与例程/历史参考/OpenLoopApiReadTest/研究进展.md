# GVN 开环力控研究进展与轨迹规划

## 当前阶段

目标是在直线电机进入 GVN 开环力控模式后，把期望力轨迹转成随时间变化的电流指令，并通过 DAC 接口按时下发。本阶段已验证**正向变 DAC 指令能引起可重复的电流反馈变化**。下一阶段需要把固定波形点表换成由期望力和模型生成的点表，再用独立力数据评价加载与保持效果。

合并早期 21 个完整脉冲与后续 107 个完整脉冲，0～360 正向 DAC 下的经验关系为 `Δraw ≈ 0.135556 × DAC − 0.186912`，RMSE 为 0.305 raw。量化和短脉冲时序决定了适用范围。目标 0 单独用零指令表示。安培换算、负 DAC 对应的电流方向、长时输出和闭环力调节仍待验证。

1 ms 加密采样尝试在全零阶段超期，未发送非零波形。三波形实测在正弦形归零观察中迟到 1.702 ms，S 型未发出。最新 CPP 将短时迟到的零观察点顺延，严重零阶段超期经实时状态复查后走正常回切。该改动通过假 API 回归，S 型及改动后的整轮流程仍待实机验证。用户曾现场确认上一轮模式恢复且已撤使能，后续上机仍需重新读取状态。

## 从波形测试接到电流轨迹规划

现在使用 **2 ms 目标周期和 11 点点表**。切入开环的初始 DAC 为 0，每拍调用 SetForceValue 更新一个整数 DAC 值，读回目标并采集有符号电流。QPC 记录实际时间，电流反馈用于验证和保护。DAC 在两个发送时刻之间保持，反馈峰值晚一拍是本次采样观察，精确时延和带宽尚未测定。

| 正向波形 | 上升段点值 | 最大相邻 DAC 变化 |
|---|---|---:|
| 三角波 | 0、20、40、60、80、100 | 20 |
| 正弦形 | 0、10、35、65、90、100 | 30 |
| 五次 S 型 | 0、6、32、68、94、100 | 36 |

S 型采用五次平滑函数，使起点、峰顶和终点附近的变化更缓。相同峰值和时长下，中段变化更集中。需要减小阶梯跳变时，在生成点表时同时约束幅值和相邻 DAC 变化，按约束选择过渡时间。保持和卸载也要进入同一个点表，并记录实际发送时间。

待实施的链路是 `期望力 → 模型给出的电流目标 → 同单位的 DAC 换算 → 限幅与相邻步长约束 → 2 ms 逐点执行 → 力与电流数据评价`。

1. 先明确模型输出单位。若使用空载模型和残差估力，先统一空载基准和加载增量的 raw 定义，并验证期望力到加载电流增量的关系。已有 DAC 到 raw 的经验式只能承担最后一段换算。安培制规划需补充独立的 raw 到安培依据。
2. 先用同峰值、同周期补齐 S 型和正常退出证据。需要双向轨迹时单独确认负目标写入、读回和实际反馈符号。
3. 再用期望力生成加载、保持与卸载点表。记录目标力、参考力、DAC、反馈电流、位置和真实时刻，分别评价加载误差、保持误差与切换过程。实机力精度以力数据为准。后续学习以精度和连续确认作为停止条件，候选、失败和确认试次均计入成本。
