# 第一阶段 Z 轴位置相关空载电流辨识

本目录包含一个 VS C++ 项目、四个采集入口和独立的离线分析脚本。Z 轴实验指令区间为 **0～32000 脉冲**，轴映射为核 2、轴 1、别名 a33。现有控制台输入和 CSV 的 `*_mm` 字段按 1000 脉冲/mm 换算。反馈字段 `current_fb_raw` 保存 `GTN_GetAtlTorque` 的有符号读数。项目构建时复制[基础调试工程配套 SDK](../00_平台配置与基础调试/README.md)的 x64 DLL。

## 最终模型与独立验证

采用[静态双向保持单表](models/position_B_primary_v1.json)作为最终位置项。每个位置先在同一轮取正反向末 1 s 电流的半和，再对两轮等权平均。模型覆盖 **1～31 mm（1000～31000 脉冲）**，包含 301 个节点，节点间线性插值，输出有符号电流 raw。0～32 mm 为实验指令区间，查询超过模型端点时留空。[模型节点](models/position_B_primary_v1.nodes.csv)

分段线性、PCHIP、二次和全程线性的开发集 RMSE 分别为 4.54、4.61、9.51、9.62 raw。分段线性保留局部变化，精度与 PCHIP 相当。对照方案在 3.5～22 mm 内对静态中心赋 50% 权重，对三档恒速中心各赋 1/6 权重。

| 独立检验 | 主表评价范围 | RMSE / P95（raw） |
| --- | --- | --- |
| D1 未见位置，51 对 | 1.55～30.55 mm，17 点 | 8.18 / 13.94 |
| D2 同日另时段，24 对 | 4～30 mm，8 点 | 7.97 / 13.93 |
| D3 留出恒速 2 mm/s，2 个往返 | 1～31 mm | 7.59 / 13.79 |
| D3 留出恒速 10 mm/s，2 个往返 | 1～31 mm | 6.59 / 12.54 |
| D3 留出恒速 40 mm/s，2 个往返 | 3.25～28.50 mm | 6.09 / 11.14 |

D1、D2 分别完成 102、48 次到位，缺测均为 0。30 mm 复测的最大绝对误差为 11.26 raw。共同区间内，静态单表与融合表的 RMSE 在 D1 为 7.95／8.72 raw，在 D2 为 8.03／8.09 raw。融合表在三档恒速留出往返上降低了重叠区误差。最终采用覆盖更宽的静态单表作为统一位置基准。保持第 4 秒，扣除位置项后，正向平均残差为 +22～+27 raw，反向为 −22～−23 raw，供后续摩擦与到位历史辨识使用。

## B 加密静态保持

B 的主网格是 1000～31000 脉冲，每隔 100 脉冲取一点，共 301 个双向节点，两侧接近距离均为 1000 脉冲。每次保持 4 s，保存完整波形，取末 1 s 拟合前配对。第一轮先正向、第二轮先反向，每轮 602 次，两轮共 1204 次，单轮仅保持约 40 分钟。高级模式允许单独运行一轮并指定起始方向，也可以安排第三轮。

| 控制台协议 | 点列 | 接近和用途 |
| --- | --- | --- |
| `B` | 1000～31000 脉冲 | 每点双向，主网格建模 |
| `BL` | 1000→0 脉冲 | 11 个反向单向点，接近距离 1000 脉冲 |
| `BH` | 31000→32000 脉冲 | 11 个正向单向点，接近距离 1000 脉冲 |
| `BE` | 500～1000、31000～31500 脉冲 | 默认短距离 500 脉冲双向接近，共 24 次，在 1000、31000 脉冲与主网格比较。高级模式可在 100～900 脉冲间选短距离，自动生成可双向接近的 100 脉冲节点 |

边界协议使用各自会话，单向值与短接近双向值均保留供诊断。主网格训练使用 `B` 的完整双向组。粗网格仍可独立回放。A2 和此前 B 的 8000、16000、24000 脉冲可作为跨会话对照。100 脉冲是点列间距，模型精度以 D 未参与拟合节点的 raw 电流预测误差评价。

## C 恒速扫描

运行 `scan_velocity` 入口。在 2、10、40 mm/s 各完成 5 个往返，三档交错运行，共 30 趟。实测加减速度设定为 400 mm/s²。每档前 3 组进入开发集，后 2 组在模型冻结后评价。换向点为 0、32000 脉冲，选端点的局部反馈余量与 B 相同。

C 默认使用 Windows 高分辨率计时器，请求周期 5 ms。5 s 实机只读测速的平均间隔为 5.91 ms，P95 为 6.12 ms，无缺测。程序用编码器位移检查方向，保留 SDK 速度反馈。离线用编码器位置和实际时间戳，在每个候选样本两侧各取约 50 ms 估计速度和加速度。速度、加速度及连续性筛选后，每趟保留最长连续匀速段，按双向共同覆盖的实际位置配对。[只读测速](verification/c-5ms-read.log)

点表显示各档理论匀速长度，以及按两侧各 50 ms 内收的预计有效区间。离线预览候选为 `2,400` 和 `2,10,40`，加减速度为 400000 脉冲/s²，对应单轴测试界面的 0.4 脉冲/毫秒²。最高档的理论匀速长度为 28000 脉冲，按上述内收估算为 4000～28000 脉冲。若采用 200000 脉冲/s²，最高档预计为 6000～26000 脉冲。正式运行填写现场确认的数值，实际有效段由正反向记录共同确定。

## 入口与点列

| 入口 | 控制台协议 | 默认点列或重复 |
| --- | --- | --- |
| `read_state` | 只读确认 | 记录位置、速度、电流、模式、状态、限位、温度和返回码，汇总实际周期、读耗时和缺测 |
| `hold_positions` | A0 | 0、8000、16000、24000、32000 脉冲。0 只从较大坐标到达，32000 只从较小坐标到达 |
| `hold_timeseries` | A1 | 输入 A0 确认的代表点，每个位置连续保持后再移动。每段候选 10 s，共 3 段，可在现场输入扩展时长 |
| `hold_positions` | A2 | 输入有双侧接近余量的代表点，每个方向默认独立到位 5 次，方向和位置轮换。保持 4 s，取第 4 秒 |
| `hold_positions` | B、BL、BH、BE | 主网格、低端单向、高端单向、短接近双向对照，均保持 4 s，取第 4 秒 |
| `scan_velocity` | C | 0→32000→0 脉冲，三个速度交错，各 5 个完整往返。每个速度前 3 组用于开发，后 2 组留出 |
| `hold_positions` | D1 / D2 | D1 固定 17 个留出位置、102 次到位。D2 固定 8 个复测位置、48 次到位。每位置双向各 3 次 |

A0、A2、B、D 共用独立接近逻辑。程序读取接近前的实际起点，检查距离和实际到达方向。A0 默认保持 2 s，A2、B、D 保持 4 s。各协议使用末 1 s 的有效窗口，离线按实际时间戳积分计算均值。

A2、B 和 C 的运动方向以编码器位置轨迹为准。相对行程中最远进度出现超过位置容差的反向位移时中止。到位和保持窗口检查轴状态的运动位、位置容差与采样间隔，速度反馈读数保留供排查。

A2 诊断同时输出第 3 秒和第 4 秒的逐次均值与差值，并按位置、方向汇总有效配对数和绝对变化。归档的 2 s 会话可按原末 1 s 回放，第 3、4 秒字段留空。

A0、B 和 C 的运动指令限于 0～32000 脉冲。默认到位容差为 ±10 脉冲，上端点窗口为 31990～32010，下端点窗口为 −10～10。端点外的反馈余量只适用于对应端点的运动、保持和向内离开，回到工作区间后撤销。若启动时反馈略微在边界外，须读到静止状态且规划位置正位于对应端点才可从该处向内转场。报警、限位、使能和静止条件继续检查。高级设置可以收紧端点到位容差，端点反馈余量上限仍为 10 脉冲。

C 直接从一个端点换向到另一个端点时，起点余量保留到反馈进入 0～32000 脉冲。目标端点的余量用在另一个边界。中止时平滑停返回后立即记录触发试次、原因和已采数据，随后核对停稳。

## 构建与运行

用 VS 2022 打开 [ZRPositionCurrent.vcxproj](ZRPositionCurrent.vcxproj)，选 x64。Debug 默认沿用现场选中的 `scan_velocity`，Release 默认是 `read_state`。在 VS 中切换时，修改工程文件中对应配置的 `EntryPoint`，重新加载工程。也可在 VS Developer PowerShell 使用下面的命令覆盖入口。两个配置均只编译所选的 `main` 和公共采集模块。

```powershell
MSBuild .\ZRPositionCurrent.vcxproj /p:Configuration=Release /p:Platform=x64 /p:EntryPoint=hold_positions
.\bin\x64\Release\hold_positions\ZRPositionCurrent.exe --plan
```

`--plan` 只验证并打印点表。离线预览可回车采用候选运动参数。现场运行省略 `--plan`，运动数值填写现场确认值。

- 只读入口启动后回车，使用 5 s、10 ms 和已读通的索引 1。
- 日常 A0 启动后回车选择 A0，在同一行输入速度和加减速度，例如确认后输入 `2,20`。程序显示 8 次保持点表和实际采用的默认值。核对后输入 `START`。
- A1/A2 代表位置为 8000、16000、24000 脉冲。按当前控制台单位输入 `8,16,24`。A1 上电时长已知时填写，回车记为缺测。C 的三个确认速度在同一行输入。D 直接选 `D1` 或 `D2`。
- 静态实验默认请求采样周期 10 ms，接近偏移 1000 脉冲。控制环索引 1，预期位置模式值 2，位置容差 10 脉冲、静止速度容差 50 脉冲/s、到位超时 30 s。A0～B 实测平均采样间隔为 15.44～15.57 ms。已完成会话的转场和加减速设置为 2000 脉冲/s、20000 脉冲/s²，控制台输入 `2,20`。默认配置标识为 `a33_core2_axis1`，运动会话记录为操作者确认 R 轴已固定。
- 若设备配置或 R 轴固定方式有变化，启动时加 `--advanced` 更新记录。高级模式也可修改采集参数、A1 段数和时长、D 点列等。每项显示默认值，回车保留。可与 `--plan` 一起使用。

现场完成回零、限位、停车余量、抱闸和撤使能顺序确认，使用已经使能的 Z 位置伺服及 TRAP 规划模式，固定 R 轴。点表核对后输入 `START`。程序只向已就绪的 Z 轴提交规划指令，核查平滑停参数、规划位置和反馈位置。按 Q 或 Ctrl+C 中断，运行中由程序尝试提交平滑停，返回码写入 manifest。现场急停、抱闸与撤使能按设备流程操作。TRAP 加减速按本次输入写入控制卡。停机期间的读数取决于控制卡通信状态。

原始数据写入 `data/raw/<session>.csv`，按试次刷新。每个会话在 `manifest/` 中记录实际配置和参数、完整计划表以及逐试次结束状态。记录包含转场、接近、保持、扫描及换向阶段。A1 的上电时长由操作者输入起始读数，后续按单调时钟推算。温度列为可读的卡温，读取失败时留缺测和返回码。

已整理的会话以 `实验简称_YYYYMMDD-HHMMSS_序号` 为前缀。当前采集程序仍会生成旧格式编号，整理时须成组更新文件名和内部 `session_id`，以便离线回放。

## 离线分析

使用 Node.js 22 或以上。以下命令在项目目录执行，`.` 指本项目。会话编号取实际文件名，也可将 `.` 替换为包含 `data/raw` 和 `manifest` 的数据目录。

```powershell
node scripts/analyze.mjs diagnose . A0会话 A1会话 A2会话
node scripts/analyze.mjs summarize-b . B主网格会话 BL会话 BH会话 BE会话
node scripts/analyze.mjs freeze . B会话 C会话 --quadratic
node scripts/analyze.mjs evaluate . D未见会话 D跨时段会话 C会话
```

- `diagnose` 输出 A0 代表点和峰值、A1 连续保持段噪声与漂移、A2 各位置各方向的独立到位标准差。以 A0 实测和现场状态确认代表点。
- `summarize-b` 按会话输出正向均值、反向均值、半和、半差和末窗口实际反馈位置。提供主网格与 `BE` 会话时，在相同速度、相同节点上按方向比较两种接近距离。
- `freeze` 按 B 完整组与留出位置联合交叉验证，比较常值、线性、PCHIP，以及以开关选配的二次模型。C 开发组用于核对各速度的双向半和与 B 的一致性，按 250 脉冲网格对齐。若 C 采用 40000 脉冲/s，5 ms 对应约 200 脉冲/样本。正式扫描后用会话实际时间戳核对采样、缺口和匀速覆盖。
- `evaluate` 使用冻结的模型、实际训练节点及分析版本，拒绝把 B 训练点作为 D 未见位置。按未见位置、跨时段和各速度扫描留出组报告 RMSE、绝对残差 P95 及相对常值模型改善率。模型仅在有效范围内预测。模型或筛选规则更新后，在新的分析目录冻结，并使用新的独立验收试次。
- 本轮 D 的指定双表用下文的 `freeze-d-models` 和 `evaluate-d`。上面两个入口保留给自动选模的对照流程。
- `models/position_current.json` 保存冻结模型、候选、适用配置和数据证据。`results/` 保存配对数据、排除原因和 A2 参考。`data/figures/` 保存实验数据图像及开发、验收对照图。扫描覆盖不足的位置和速度可结合图表、CSV 覆盖列和排除表检查。

## 验证状态

### D 指定模型验收

`freeze-d-models` 按两轮加密 B 冻结 1000～31000 脉冲的 301 点主表，并用 C 各速度第 1～3 组冻结 3500～22000 脉冲的 38 点方案③。两张表均分段线性插值，有效域外留空。方案③节点权重为 B 的 1/2，各档 C 的 1/6，节点来源值保存在 `models/position_BC_overlap_v1.nodes.csv`。

```powershell
node scripts/analyze.mjs freeze-d-models . Z-B_20261124-170633_02 Z-C_20261124-165139_02
node scripts/analyze.mjs evaluate-d . Z-C_20261124-165139_02
node scripts/analyze.mjs evaluate-d . Z-D1_20261124-201558_01 Z-D2_20261124-202754_01
```

第一条命令用于首次冻结，项目已有 v1 文件时会拒绝覆盖。第二条只计算 D3，第三条加入实测 D1、D2 并自动读取同一个冻结 C 会话的第 4、5 组。

现场打开新版 `hold_positions`，选择 `D1` 或 `D2`。回车采用与加密 B 相同的 `2,20`，即 2000 脉冲/s、20000 脉冲/s²。固定接近距为 1000 脉冲，保持 4 s，末 1 s 为主窗口。D1 预览应为 102 次、D2 为 48 次；D2 另开实际采集时段。确认点表及现场状态后输入 `START`。

评价输出按批次写入 `results`，分别提供静态第 1～4 秒窗口、双向中心、单方向残差、各口径误差、C 的每档每往返覆盖和排除原因。双模型指标只使用两表同时覆盖的相同记录；残差符号为实测减预测。第 1 秒从实际首个有效保持样本开始积分，窗口表带实际积分时长。输出图写入 `data/figures`，静态对照和逐秒方向图在有 D1/D2 数据时生成。
