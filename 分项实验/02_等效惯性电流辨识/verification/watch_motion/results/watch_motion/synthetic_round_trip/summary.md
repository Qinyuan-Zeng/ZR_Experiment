# Watch 运动回放 — synthetic_round_trip

**记录到往返范围，运动覆盖有时钟断点**

- 8161 帧，核周期 50 µs，时间轴 410 ms，断点 1 处。
- 实际起点 / 折返点 / 终点（mm） 0 / 1 / 0。
- 去程 / 回程有符号位移（mm） 1 / -1，折返位置时间 174.5 ms。
- 持续运动方向 1 → -1。录到起步前静止 是，录到末端静止 是，返回起点 是，运动覆盖连续 否，与预期端点匹配 是。
- 预期工况 0 → 1 → 0 mm，10 mm/s，400 mm/s²。实际运动按编码器判定，换算比例 1000 pulse/mm。
- 位置线性拟合窗 5 ms，加速度差分跨度 5 ms。运动 / 静止速度阈值 0.3 / 0.15 mm/s，加速阈值 40 mm/s²，匀速和静止加速度上限 20 mm/s²。
- 短于 2 ms 的分段标为过渡。方向最短持续 8 ms，端点静止最短 10 ms，位置容差 ±0.05 mm。
