# 第三阶段 C 启停与运动历史

C 用空载 Z 轴的位置伺服和单轴 TRAP，R 固定。比较相同位置、同一探测方向与探测速度下，不同到位方向、停留时长和低速条件对启动及停止瞬态的影响。停留和运动段都在同一次 Watch 记录中。分析比较用编码器得到的实际位置、速度与加速度，在状态重叠区比较机理残差，以整试次为重复单位。直接启动的基线有固定的慢速到位和 2 s 停稳等待，应保留其已知历史。跨历史同状态配对仍需在实际数据中核实。

## 运动参数

| 参数 | 设置 |
|---|---|
| Z 坐标 | 1,000 pulse/mm，重启点 16,000 pulse，试验端点 12,000 和 20,000 pulse |
| 探测段 | 16,000 → 20,000 或 16,000 → 12,000 pulse，2、5、10 mm/s，等加减速 400 mm/s²，TRAP 平滑 0 ms |
| 直接启动 | 从探测起点的对侧端点沿探测方向，以 2 mm/s、20 mm/s² 到达 16,000，连续停稳 2 s 后执行探测 |
| 同向重启 | 从对侧端点沿探测方向，以 10 mm/s、400 mm/s² 到达 16,000，停稳 0.2、0.5 或 1 s 后执行探测 |
| 反向重启 | 从探测终点以 10 mm/s、400 mm/s² 向 16,000 到位，停稳 0.2、0.5 或 1 s 后向原端点返回 |
| 记录窗口 | 到达试次准备端后，先采 250 ms 停稳。连续采集到位、中心停留、探测及结束后 500 ms 停稳 |
| 转场 | 自动读实际停稳位置，按 2 mm/s、20 mm/s² 转到本试次准备端。转场保护速度 5 mm/s，测量段保护速度 15 mm/s |
| 待现场确认的保护值 | 0～37,000 pulse，停车附加余量 4,000 pulse，跟随误差上限 500 pulse，最低平滑停减速度 0.99 pulse/ms² |
| 采样与插补 | 核周期读回 50 µs 才采集，Watch 每核周期记录时钟、编码器位置、反馈电流。主机状态请求间隔 5 ms，实际间隔以时间戳为准。单轴 TRAP 由卡内规划器执行，代码未单独设置插补周期 |

正向示例为直接或同向 12 → 16 → 20 mm，反向重启 20 → 16 → 20 mm。负向用镜像路径。停留以连续停稳窗口计时，文件同时保存到位确认至下一指令的实测时长。首版包含 42 个工况 × 3 次，共 126 个试次。前 6 个是计入正式矩阵的试采，最多每批 3 个。5 s 诊断留待首批波形决定。

## 运行

在工作区根目录用 PowerShell 执行。Release x64 的工程入口为 `EntryPoint=c_scan`。

```powershell
$py = 'C:/Users/HYB/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
$run = '.\分项实验\03_摩擦与残差补偿\scripts\c_run.py'
& $py $run --plan --pilot
$id = 'Z-C-HISTORY-01'
& $py $run --freeze $id
& $py $run --pending $id --pilot
```

上述命令离线。冻结时输入本轮确认的保护值，回车采用屏幕显示值，最后输入本轮协议 ID。试采现场确认设备、协议和允许范围后执行下列命令。输入实际现场会话 ID、`READY`，独立状态及路线校核通过后输入 `START`。当前 Z 位置自动读取，通常无需手工设置。控制台 Ctrl+C 请求平滑停机。

```powershell
& $py $run --batch $id --pilot
& $py $run --pending $id --pilot
& $py $run --replay $id
```

前 6 个试采需分两批。试采结果确认后，去掉 `--pilot` 可按冻结点表续采。回放检查同步帧连续性、行程及实际速度、停留窗口和主机状态。中断原始记录保留，按整试次补采。原始数据保存于 `C/data/raw`，冻结协议与批次记录在 `C/manifest`，验收汇总在 `C/results/<协议ID>/accepted_trials.csv`。

后续比较按探测方向、实测状态与停留阶梯分组，检验加入只用当前和过去数据构造的速度历史及停驻时间后，启动、减速和零速衔接误差是否稳定改善。启动窗口电流峰值可用于查看原始信号，机理残差需扣除已冻结且处于有效域的电流项。近零速不直接外推滑动 F1。长期保持由 D 研究，独立验证轨迹留给 E。
