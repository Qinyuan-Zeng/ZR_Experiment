# 第三阶段 B1 动态残差采集

B1 使用 Z 轴位置伺服和单轴 TRAP，R 固定，无接触。每个往返在同一路径、速度和加减速度下完成正反两腿。每腿先转场到起点，再采连续停稳预保持、完整加速–匀速–减速以及到位后连续停稳。转场单独留在 SDK 记录，Watch 测量从起点的预保持开始。

## 入口与操作

本项目从 VS 2022 Developer PowerShell 编译。以下命令在工作区根目录运行。

```powershell
$a = '.\分项实验\03_摩擦与残差补偿'
$py = 'C:/Users/HYB/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
$b1 = "$a\scripts\b1_run.py"
msbuild "$a\ZRFrictionCurrent.vcxproj" /p:Configuration=Release /p:Platform=x64 /p:EntryPoint=b1_scan
& $py $b1 --plan --pilot
& $py $b1 --plan
```

预览只读取 B0 缺口矩阵。全表包含 32 工况、160 往返和 320 趟测量。10 个试采往返是第一轮的前十个点，通过相同冻结验收后直接计入正式重复数。

现场确认设备配置、保护和执行范围后，使用同一个协议 ID。现场会话 ID 按实际采集时段填写，S2 使用与 S1 不同的会话 ID。

```powershell
$id = 'Z-B1-01'
& $py $b1 --state
& $py $b1 --freeze $id
& $py $b1 --batch $id --pilot
& $py $b1 --pending $id --pilot
& $py $b1 --replay $id
```

每次执行最多 4 个待采往返。冻结时按提示确认保护边界、停车附加余量、跟随误差上限、最低平滑停减速度和测量速度保护。独立批前状态与全批路径校核是启动条件，先确认 `READY` 再按预览确认 `START`。实机出现异常即停批，独立批后检查后才进入回放。有效整对逐个记账，失败的腿随会话保留，下一次重采整对。试采验收后可用 `--batch $id` 继续正式点表。`--replay` 复查既有输入哈希和未入账的完整批次。

## 插补与采样周期

| 名称 | B1 设置或读数 | 作用 |
|---|---|---|
| 单轴 TRAP 插补周期 | 程序没有独立设置 | 命令向卡写入端点、目标速度、加减速度及 0 ms 平滑，由卡内规划器生成轨迹 |
| 控制卡 Core 2 核周期 | 历史读回 50 µs，B1 批次启动时用 `GTN_GetCorePeriod` 和卡内毫秒／中断钟复核 | 这是读回的控制卡核周期。独立插补周期或驱动电流环周期未单独测得 |
| Watch 采集周期 | SDK `interval=0`，按一核周期一帧布置，期望 50 µs | 同卡帧记录编码器和电流，批后按真实 tick 检查连续性 |
| 主机状态轮询 | 请求等待 5 ms，实际由主机时间戳统计 | 记录状态、指令位置／速度、跟随误差及保护信号 |
| 离线分析网格 | 计划沿用 B0 的 5 ms | B1 首轮保留 50 µs 原始数据；分析网格不改控制器设置 |

因此给老师汇报时可以说：本次采用卡内单轴 TRAP，控制卡核周期历史实测 50 µs、B1 每批复核；没有另设插补周期。Watch 预期按 50 µs 采集，主机约 5 ms 做状态轮询。

## 运动和参数

试采首批的第一个测量起点由点表给定，为 22,000 pulse，P1 第一个往返为 22,000 → 10,000 → 22,000 pulse。程序独立读取当前停稳位置，确认转场余量后按 2 mm/s 转场。无需在程序中填写当前位置，转场单独记录。若轴仍在 31,500 pulse 附近，沿表中的 0～37,000 pulse 候选边界和保护值可通过该段离线校核。

P1 覆盖现有 F1 的 10～22 mm 验证区，P2 在该区内改变两端位置和路径长度。B1 用这两条路径比较同一冻结摩擦基线内的动态残差。接近全行程时，加减速和起停会进入 F1 尚未独立验证的两端区域，如果后续应用确实需要更长路径，应先核查覆盖缺口并经用户确认，再单独评价超出 F1 位置验证域的误差。

| 工况 | 参数 |
|---|---|
| P1 | 10 ↔ 22 mm（10000 ↔ 22000 pulse） |
| P2 | 12 ↔ 20 mm（12000 ↔ 20000 pulse） |
| 首次试采 | 两条路径各做 10/400、20/400、20/600、40/400、40/600，一条件一整对。数值单位分别为 mm/s、mm/s² |
| 正式矩阵 | 2、5 配 400；10 配 400、600；15、20、30、40 配 400、500、600；上述 16 组乘两条路径 |
| 重复安排 | 每条件 5 往返，S1 三轮＋S2 两轮，轮次之间调整条件顺序及首发方向 |
| 转场 | 2 mm/s，20 mm/s²；转场保护速度上限为 5 mm/s |
| 测量段 | 速度按工况；加速＝减速，TRAP 平滑时间 0 ms。实际加减速度、速度和目标位置保存回读 |
| 保持 | 每腿运动前、运动后各持续停稳 1 s。每一保持窗口最多等待 2 s，未满足则停批 |
| 几何与保护默认候选 | 0～37000 pulse，停车附加余量 4000 pulse，跟随误差上限 500 pulse，最低平滑停减速度 0.99 pulse/ms² |
| 需现场确认 | 测量段速度保护候选 50 mm/s，测量指令最高 40 mm/s。停车预算按冻结保护速度计算。电流与卡温不设 B1 软件阈值。继续采集反馈电流和卡温，依赖现场确认的设备侧保护，并检查驱动报警 |

低速 2 mm/s 在 400 mm/s² 下理论加速约 5 ms，先检查原始 Watch 鉴别能力及触发对齐，再决定低速阶段采用的分析网格。请求周期、速度计划、状态采样和图表一律以实测时间证据为准。
