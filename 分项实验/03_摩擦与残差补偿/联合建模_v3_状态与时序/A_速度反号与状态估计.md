# A 速度反号与状态估计

开发选择 **S0**。改进型首位为 **S2**，供联合消融使用。S0 与 S2 在开发侧的固定机理加载误差几乎相同。S2 主要修正短时符号和静止波动。表现最好的 S3 候选仍推高加载误差，减速误差超过 S0 的两倍。S3 各组合的结果见同点覆盖和机制域交集表。

## S1 数据可用性

464 条原始 Watch 均只有帧号、卡 tick、编码器位置、反馈电流。SDK 旁路通过 `GTN_GetAxisEncVel` 记录反馈速度和返回码，但每次主机读取跨度内包含多个 API 请求，记录没有专属于反馈速度的卡时间戳。下表周期是读取间隔，不能由此推出控制器速度更新周期或其内部滤波。记录中这些速度多见 20 pulse/ms 的台阶，明显粗于低速试验的 2–5 pulse/ms。无法构造同步、可辨的 S1，故标记不可用。

## 减速末端复现与全记录扫描

B1 R5-P2-V40-A600 正向腿帧 26200 位于 19978 pulse，原始 Watch 前后各 5 ms 位移分别为 0 和 0 pulse。S0 算得 -2022.9 pulse/s，S2 为 0.0 pulse/s。该点反馈 623 raw，滑动摩擦由 -98.91 变为 0.00 raw，冻结 M1 由 443.13 变为 542.04 raw。该点保留在原评价掩码。

静止位置方差的训练侧第 90 百分位给出两折 R 基数 3.200、3.235 pulse²。整数编码器的量化方差下限为 1/12 pulse²。静止测量中的位置波动也可能含真实伺服运动，因此采用该基数及其四倍作保守搜索。S3 只以位置测量更新；位置项仍查原编码器位置，变化仅沿惯性、滑动摩擦和后续残差传播。

对未通过主门槛的状态估计保留原辨识系数。新速度和加速度分布与原惯性标定域及 F1 支持域的重叠见覆盖表。退出滑动项的回退点仍计入固定掩码评分。机制域新增点只是候选支持范围，部分差异来自未套用原双窗口一致性规则。原数据未因此新增监督标签，另表按同一七点参考重做一致性敏感性。原静态 HOLD 置零沿用冻结回放条件，部署时的停驻进入判据仍需单独验收。
