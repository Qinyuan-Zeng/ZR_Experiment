## A0 稳态摩擦预筛

A0 用位置模型扣除空载电流的位置项，在相同位置比较正反向的稳态残差。用 10,000 脉冲/s 与历史 C 做会话对照，用 20,000 检查中速增量，用 5,000 检查低速段形状。每档一个完整往返，用于决定正式 A 的采集点表。

### 1. 编译与离线预览

在 VS 2022 打开 [ZRFrictionCurrent.vcxproj](ZRFrictionCurrent.vcxproj)，选择 Release | x64 并生成。也可在 VS 2022 Developer PowerShell 中从工作区根目录运行：

```powershell
$a0 = '.\分项实验\03_摩擦与残差补偿'
msbuild "$a0\ZRFrictionCurrent.vcxproj" /p:Configuration=Release /p:Platform=x64
$exe = "$a0\bin\x64\Release\a0_scan\ZRFrictionCurrent.exe"
& $exe --plan
```

预览可连续回车采用候选值。第一行 `2,400` 分别是转场速度（mm/s）和加减速度（mm/s²），第二行 `0,32` 是低、高换向位置（mm）。本台 1,000 脉冲/mm。程序预览固定顺序 10,000、20,000、5,000 脉冲/s，每档先正向后反向，合计六趟。按两侧各约 50 ms 内收后，每档的预计匀速窗口均须覆盖 3,500～22,000 脉冲。预览用于确认点表和几何窗口。

### 2. 现场采集

冻结本轮协议 ID、参数和六趟点表。现场确认 Z 就绪、R 固定、限位、急停、抱闸和停车余量。批前独立只读检查状态，从实际停稳位置校核到首个换向点的转场路径及整批停车余量。按 [实机运行约定](../../经验与规则/编程与运行约定.md) 留存批前、批后状态。

```powershell
& $exe
```

显式输入本轮确认的两行参数，核对预览后输入冻结协议 ID，再输入 `START`。运行中按 Q 或 Ctrl+C 可请求程序平滑停机。程序打印会话号，原始 CSV 保存到本目录的 `data/raw`，参数、计划和试次状态保存到 `manifest`。出现异常时保存退出信息并独立检查轴状态。现场条件变化或状态检查异常时停止发起新运动。

### 3. 回放

从工作区根目录运行，使用已安装 NumPy、ReportLab 的 Python 3。将 `<会话号>` 替换为程序输出的 `Session` 值。

```powershell
python "$a0\scripts\a0_replay.py" --session '<会话号>'
```

省略 `--session` 时回放第一阶段 C 会话 Z-C_20261124-165139_02 的开发集，速度为 2,000、10,000、40,000 脉冲/s，每档三个往返。两种回放共用 `position_B_primary_v1` 位置表和第二阶段原 B 矩阵的 fitZero 区间。程序核对会话状态、信号配置、试次用途、完整性和双向配对，保存原始数据哈希。

对每趟扫描按真实时间戳在采样点两侧各取约 50 ms，用编码器位移估计两侧速度、中心速度与加速度。沿用位置表保存的速度容差（10%）、加速度和采样间隙判据，检查运动位、使能、位置模式、报警及限位。选取位移最长的连续单调匀速段，在表内逐样本计算反馈电流减位置项。新 A0 会话要求六趟都完整覆盖 3500～22000 脉冲，每 250 脉冲线性插值，共 75 点。覆盖不足时回放报告试次与实测范围。历史 C 回放沿用共同覆盖裁剪。各位置等权，正负方向按同一组、同一速度和位置配对。独立重复的统计单位为整个往返。惯性敏感度按候选系数区间的最大绝对值乘实测重建加速度绝对值计算，用于估计量级。

结果位于 `results/<会话号>.stage3_A0/`。`pairs.csv` 按往返列出试次号、实测速度、方向残差和惯性敏感度。新会话额外列出各方向的实际匀速覆盖。 `profiles.csv` 保留逐位置配对。 `summary.csv` 按速度汇总方向残差、半差、半和及样本标准差，单往返的标准差留空。 `sources.json` 保存输入和脚本哈希、窗口、网格及新会话的协议 ID。图位于 `data/figures/<会话号>.stage3_A0.svg`。

先与历史 10,000 脉冲/s 档比较。该档半差为 99.75 ± 0.98 raw，正向与反向残差均值分别为 +95.75 和 −103.74 raw。确认对照后，再用同会话 20,000 与 10,000 的差值判断中速增量，并结合 5,000 档检查低速形状。
