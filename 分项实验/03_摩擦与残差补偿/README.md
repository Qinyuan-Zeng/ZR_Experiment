## A0 稳态摩擦预筛

在本目录用含 NumPy、ReportLab 的 Python 3 运行 `python scripts/a0_replay.py`。脚本只读取工作区文件。输入固定为第一阶段 C 会话 Z-C_20261124-165139_02、位置表 position_B_primary_v1 和第二阶段原 B 矩阵的 fitZero 区间。开发集每档 3 个往返，速度为 2000、10000、40000 脉冲/s。程序核对配置、原始 CSV 哈希、试次用途、完整性与双向配对。

对每趟扫描按真实时间戳在采样点两侧各取约 50 ms，用编码器位移估计两侧速度、中心速度与加速度。沿用位置表保存的速度容差（10%）、加速度和采样间隙判据，检查运动位、使能、位置模式、报警及限位。选取位移最长的连续单调匀速段，在表内逐样本计算反馈电流减位置项。所有往返取共同覆盖与 3500～22000 脉冲的交集，每 250 脉冲线性插值。各位置等权，正负方向按同一组、同一速度和位置配对。独立重复的统计单位为整个往返。惯性敏感度按候选系数区间的最大绝对值乘实测重建加速度绝对值计算，用于估计量级。

结果位于 `results/Z-C_20261124-165139_02.stage3_A0/`。pairs.csv 按往返列出试次号、实际速度、位置范围、方向残差与惯性敏感度。profiles.csv 保留逐位置配对。summary.csv 按速度汇总方向残差、半差、半和及往返间样本标准差。sources.json 保存输入和脚本哈希、窗口与网格。图位于 `data/figures/Z-C_20261124-165139_02.stage3_A0.svg`。

下一批候选速度 5000、10000、20000 脉冲/s 可用第一阶段 scan_velocity 的 `--plan` 离线预览，控制台两行分别输入 `2,400` 和 `5,10,20`（旧入口使用 mm、s，1000 脉冲/mm）。该入口生成第一阶段 C 的完整五轮点表，供核对 TRAP 几何可行性。第三阶段实测首轮另定一轮点表，确认现场执行范围与停车余量，并保存会话和批前批后状态。独立会话用于核对方向差、速度效应与重复性。
