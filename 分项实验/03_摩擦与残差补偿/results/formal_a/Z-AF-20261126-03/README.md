第五轮 17 个独立往返中，F1 的正向 RMSE 从 F0 的 **7.89** 降至 **6.11 raw**，反向从 **9.32** 降至 **8.25 raw**。正、反向绝对误差 P95 也均下降。F1 正向平均偏差为 **−2.06 raw**。 [留出评价](model_metrics.csv)
