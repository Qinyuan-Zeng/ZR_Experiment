# 分项实验

- [00_平台配置与基础调试](00_平台配置与基础调试/README.md)：通信状态、轴映射、传感器采集、坐标与限位、模式切换和点表执行。
- [01_位置相关空载电流辨识](01_位置相关空载电流辨识/README.md)：已冻结静态双向位置电流表，完成 D1～D3 独立验证。
- [02_等效惯性电流辨识](02_等效惯性电流辨识/README.md)：已完成匹配点辨识、离线积分核验及独立预测验收，冻结 B 中段惯性电流系数。
- [03_摩擦与残差补偿](03_摩擦与残差补偿/README.md)：稳态摩擦、必要的动态残差采集、网络训练和完整轨迹验证。
- [04_电流与接触力标定](04_电流与接触力标定/README.md)：已完成力采集链路、停轴首件及本机准静态电流—力初步标定。动态关系、独立验证及完整计量待开展。
- [05_电流轨迹迭代学习](05_电流轨迹迭代学习/README.md)：固定曲线、单参数与三参数对照，独立测力评价。

上述编号与分项主题对应，实际执行先后根据平台条件和试验目标决定。第四阶段已有本机准静态初步标定记录。每类实验只建一个VS项目，多个主源文件放src，每次只编译一个main。项目在具体实验确定时建立。
