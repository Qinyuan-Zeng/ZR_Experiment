# 分项实验

- [00_平台配置与基础调试](00_平台配置与基础调试/README.md)：通信状态、轴映射、传感器采集、坐标与限位、模式切换和点表执行。
- [01_位置相关空载电流辨识](01_位置相关空载电流辨识/README.md)：A0、A1、A2 和 B 已实测，当前准备 C 双向恒速扫描。模型冻结与 D 独立验证随后进行。
- [02_等效惯性电流辨识](02_等效惯性电流辨识/README.md)：匹配状态差分、实际加速度重建、积分核验。
- [03_摩擦与残差补偿](03_摩擦与残差补偿/README.md)：稳态摩擦、必要的动态残差采集、网络训练和完整轨迹验证。
- [04_电流与接触力标定](04_电流与接触力标定/README.md)：DAC与反馈电流映射、传感器标定、空载扣除后的接触力关系及独立验证。
- [05_电流轨迹迭代学习](05_电流轨迹迭代学习/README.md)：固定曲线、单参数与三参数对照，独立测力评价。

上述编号与分项主题对应，实际执行先后根据平台条件和试验目标决定。第四阶段用于补足标定环节，目前只预留目录。每类实验只建一个VS项目，多个主源文件放src，每次只编译一个main。项目在具体实验确定时建立。
