## 2026-11-18 软件环境检查

直接用VS2022打开 ZRPlatformSetup.vcxproj，选择x64，Debug或Release均可。当时使用的离线入口为src/check_environment.cpp。按Ctrl+F5运行，显示PASS表示编译、gts.lib链接、gts.dll加载通过。本入口不调用控制卡API，不需要连接驱动器或电机。

使用v143、Windows SDK 10、C++14、UTF-8及项目内配套x64 SDK，编译后自动复制DLL。SDK来自基础工程与例程/历史参考/OpenLoopApiReadTest/sdk。2026-11-18 记录为离线验证，后续第一阶段已用该配套 SDK 完成 Z 轴只读和 A0～A2 实测。

本类后续CPP入口放src下，同一个项目每次只编译一个main入口。新平台已验证的 Z 轴配置、待填写的硬件细项和实测记录统一维护在[平台配置](../../平台配置/新平台配置记录.md)。

## PCIe 控制卡通信检查

当前 Debug 和 Release 默认编译 src/check_card.cpp。选择 x64 后按 Ctrl+F5，程序打开 PCIe 连接、读取核 1 的控制卡固件版本并关闭连接。三个返回码均为 0 时显示 PASS。此项仅验证电脑与控制卡通信，无需驱动器或电机。切回离线检查时，在两个源文件的属性中对所有配置交换“从生成中排除”设置。
